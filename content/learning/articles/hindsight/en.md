# Hindsight: persistent project memory

Agents start every conversation from zero; Hindsight removes that cliff: a persistent memory per repository that keeps decisions, rationale and accumulated project knowledge, and feeds them back to the agent while it works.

## What it gives you

- **Project-knowledge search before meaningful changes:** what was already decided does not get re-decided.
- **Knowledge pages** for architecture, conventions and in-flight work, kept continuously up to date.
- **Automatic session audits:** what past sessions got right or wrong becomes searchable memory.

## How to use it

Before working on a repository, ask the agent to read the existing Hindsight pages and decisions. If anything is wrong or stale, record the correction on the spot — newer facts supersede older ones.

## Install state

The workspace chip reports whether Hindsight is present on this machine (skill and local service).
