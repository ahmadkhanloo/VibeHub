# Qoder RTL

> **یادداشت آداپتر قدیمی (۲۰۲۶-۱۰-۲۶):** این سند دربارهٔ آداپتر Qoder مبتنی بر سورس AgentRTL است. نصب‌کنندهٔ قدیمی AgentRTL انتشار VibeHub نیست و هنوز تأیید نشده که نصب‌کنندهٔ عمومی VibeHub جایگزین این قابلیت باشد. [ماتریس پذیرش انتشار](../../docs/validation/VibeHub_Release_Acceptance_Matrix.md) را ببینید.

نسخهٔ انگلیسی: [README.md](README.md)

‏ابزار [Qoder](https://qoder.com/) — محیط برنامه‌نویسی عامل‌محور هوش مصنوعی — را وادار کنید چتش را **راست‌به‌چپ** نشان بدهد؛ برای فارسی و هر زبان راست‌به‌چپ دیگر.

‏ابزارهای هوش مصنوعی فرضشان انگلیسی است. Qoder همهٔ پیام‌ها را چپ‌به‌راست رندر می‌کند؛ نتیجه اینکه جواب‌های فارسی به‌هم‌ریخته دیده می‌شوند: نقطه و ویرگول می‌افتد سمت اشتباه و کلمات انگلیسی وسط جمله می‌پرند این‌ور و آن‌ور. **Qoder RTL این را با یک استایل‌شیت ساده و تزریق در زمان اجرا حل می‌کند — بدون اینکه حتی یک فایل از خود برنامه دست بخورد.**

## 🌍 زبان‌های پشتیبانی‌شده

‏هر خط راست‌به‌چپ — جهت هر پاراگراف جداگانه تشخیص داده می‌شود، پس متن انگلیسی و بلاک‌های کد دست‌نخورده می‌مانند:

**‏فارسی** · **عربی** · **عبری** · **اردو** · **دری** · **کردی** · **پشتو** · **اویغوری** · **ییدیش** · **سندی** و …

## ✨ چه چیزی می‌گیرید

- ‏**RTL خودکارِ هر پاراگراف** — جهت هر بلاک از اولین حرف قوی آن تشخیص داده می‌شود: فارسی → راست‌به‌چپ، انگلیسی → چپ‌به‌راست؛ حتی داخل یک پیام
- ‏**متن ترکیبی درست** — پاراگراف‌های فارسی که کلمهٔ انگلیسی، عدد یا مسیر فایل دارند خوانا می‌مانند
- ‏**کد چپ‌به‌راست می‌ماند** — ‏`pre` و `code`، ترمینال، ادیتور، درخت فایل و نوار تب‌ها عمداً مستثنا شده‌اند
- ‏**باکس تایپ هم** — هنگام نوشتن، جهتش خودکار عوض می‌شود
- ‏**پوشش همهٔ فریم‌ها** — چت Qoder داخل iframe و webview رندر می‌شود، پس اینجکتور به هدف‌های تودرتو هم وصل می‌شود، نه فقط پنجرهٔ اصلی
- ‏**فونت Vazirmatn همراهِ ابزار** — فونت به‌صورت `@font-face` بیس۶۴ جاسازی شده، پس گلیف‌های فارسی درست دیده می‌شوند بدون نصب چیزی
- ‏**خودترمیم** — بعد از رفرش صفحه، در پنجره‌های جدید و بعد از ناوبری دوباره خودکار تزریق می‌شود
- ‏**نامرئی** — یک شورتکات دسکتاپ که Qoder را بدون هیچ فلاش کنسولی بالا می‌آورد و injector مخفی در پس‌زمینه می‌ماند
- ‏**قابل بررسی** — ‏`doctor.mjs` اثبات می‌کند که قواعد واقعاً فعال‌اند، به‌جای اینکه چت را خیره نگاه کنید

## 🆚 چرا پچ نکنیم و تمام؟

| روش | مشکل |
|---|---|
| ‏پچ‌کردن `app.asar` | با **هر آپدیت برنامه** می‌شکند، نیاز به **دسترسی ادمین** دارد و می‌تواند نصب را خراب کند |
| ‏تزریق CSS با DevTools به‌صورت دستی | با **هر رفرش یا ری‌استارت** می‌پرد |
| ‏کپی‌کردن جواب‌ها جای دیگر برای خواندن | هر بار از جریان کارت خارج می‌شوی |
| ‏انتظار برای پشتیبانی رسمی RTL | 🙂 |

‏Qoder RTL **هیچ فایلی از برنامه را تغییر نمی‌دهد**: از پورت DevTools خود کرومیومِ برنامه استفاده می‌کند و یک استایل‌شیت در زمان اجرا تزریق می‌کند. آپدیت‌های برنامه اثری رویش ندارند و دسترسی ادمین نمی‌خواهد.

## 🚀 نصب

فقط ویندوز. نسخه‌های قدیمی‌تر در `%LOCALAPPDATA%\Programs\Qoder` و نسخه‌های جدید در `%LOCALAPPDATA%\Programs\Qoder IDE` نصب می‌شوند؛ لانچر RTL هر دو مسیر را تشخیص می‌دهد.

### نصب خیلی سریع — یک قدم و تمام

```powershell
git clone https://github.com/ahmadkhanloo/VibeHub.git
cd VibeHub
powershell -ExecutionPolicy Bypass -File install.ps1 -Apps qoder
```

‏این یک شورتکات **Qoder RTL** روی دسکتاپ می‌سازد، با آیکون خودِ Qoder. هیچ چیزی جای دیگری کپی نمی‌شود و هیچ کلید رجیستری یا ورودی استارت‌آپ اضافه نمی‌شود.

‏اول می‌خواهید ببینید قرار است چه کند؟ `-WhatIf` را اضافه کنید — مسیر، هدف و آیکون شورتکات را بدون دست‌زدن به چیزی چاپ می‌کند.

### نصب حرفه‌ای — بازبینی کد، شخصی‌سازی، اجرا از سورس

```bash
git clone https://github.com/ahmadkhanloo/VibeHub.git
cd VibeHub
# worth a look: style.mjs (the CSS), injector.mjs (CDP client), start.ps1 (the launcher)
```

- ‏**اجرا از سورس** — ‏`install.ps1` فایل‌ها را همان‌جا که هستند نگه می‌دارد و شورتکات به همین پوشه اشاره می‌کند، پس یک کلون گیت خودش محل نصب است. بعداً اگر پوشه را جابه‌جا یا تغییرنام دهید، یک‌بار `install.ps1` را از محل جدید اجرا کنید.
- ‏**پورت دلخواه** — متغیر محیطی `QODER_RTL_PORT` (پیش‌فرض `9225`) را قبل از اجرا تنظیم کنید؛ Qoder، injector و `doctor.mjs` هر سه از آن پیروی می‌کنند. قفل اینجکتور روی `port + 1` است، پس نمونهٔ دوبله به‌جای تزریق دوتایی خودش می‌رود بیرون.
- ‏**حذف نصب** — برای نصب از سورس، `powershell -ExecutionPolicy Bypass -File install.ps1 -Uninstall` شورتکات همان checkout را حذف و injectorهای آن را متوقف می‌کند؛ فایل‌های سورس باقی می‌مانند. اگر با Setup نصب کرده‌اید، **AgentRTL** را از Settings → Apps حذف کنید.

| متغیر | پیش‌فرض | کار |
|---|---|---|
| `QODER_RTL_PORT` | `9225` | پورت DevTools؛ قفل اینجکتور یک پورت بالاتر است |
| `QODER_RTL_EXE` | کشف خودکار | مسیر کامل `Qoder.exe` یا `Qoder IDE.exe`، اگر جایش غیرمعمول است |

‏در نصب موجود و قدیمی AgentRTL Setup، اگر Qoder خودکار پیدا نشد یا در مسیر سفارشی نصب شده، مؤلفهٔ Qoder RTL را انتخاب کنید و در صفحهٔ بعد فایل اجرایی را با Browse معرفی کنید. مسیر انتخاب‌شده برای اجراهای بعدی ذخیره می‌شود.

‏کشف نسخه فقط پوشه‌ای زیر `.qoder-versions\` را برمی‌گزیند که واقعاً `resources\app.asar` داشته باشد؛ نسخه‌ای که `app.asar.qoder-pending` دارد یک آپدیت نیمه‌کاره است که بالا نمی‌آید، پس به‌جای انتخاب «بالاترین شمارهٔ نسخه» رد می‌شود.

‏پیش‌نیاز: نصب‌بودن [Qoder](https://qoder.com/download) روی ویندوز و **Node.js نسخهٔ ۲۱ به بالا** روی PATH (از WebSocket داخلی آن استفاده می‌کند).

## ▶️ استفاده

**اول Qoder را کاملاً ببندید — هم پنجره و هم آیکون System Tray** — و بعد با شورتکات **Qoder RTL** اجراش کنید. همین: از این به بعد پیام‌های فارسی راست‌به‌چپ دیده می‌شوند.

‏قفل single-instance در Qoder به پوشهٔ پروفایل گره نخورده، پس اجرای دوم فقط به نمونهٔ جاری فرانت می‌شود و پورت دیباگ باز نمی‌شود. اگر Qoder از قبل بدون پورت باز باشد، شورتکات به‌جای وانمود کردن به کارش، همین را به شما می‌گوید؛ با `The shortcut asks you to close Qoder and launch it again if it is already running without the debug port.

> ‏پورت دیباگ فقط وقتی وجود دارد که Qoder از طریق شورتکات اجرا شود؛ پس به‌جای آیکون معمولی از همین شورتکات استفاده کنید.

## 🔬 بررسی

‏لازم نیست حدس بزنید — `doctor.mjs` با همان پورت DevTools حرف می‌زند و گزارش می‌دهد صفحه در واقع چه شکلی است:

```
node doctor.mjs --targets   # چه هدف‌هایی دیده می‌شوند (page، iframe، webview)
node doctor.mjs --probe     # نودهای متنی فارسی + کلاس واقعی والدینشان
node doctor.mjs --check     # تأیید: پاراگراف فارسی واقعاً راست‌چین شد؟ (exit 1 اگر نه)
node doctor.mjs --shot      # عکس قبل/بعد از ناحیهٔ چت
```

‏`--check` همان چیزی است که باید باورش کرد: فاصلهٔ اولین گلیف از لبهٔ راست را اندازه می‌گیرد و بارگذاری Vazirmatn را تأیید می‌کند، و اگر هر فریمی رد شود با کد خطا بیرون می‌آید. برای دیدن JSON خام `--verbose` را اضافه کنید.

## 🧰 عیب‌یابی

- ‏**هنوز چپ‌به‌راست است؟** یعنی Qoder از آیکون معمولی باز شده. کاملاً ببندیدش (Tray هم) و با **Qoder RTL** بازش کنید.
- ‏**قبلاً کار می‌کرد و بعد از آپدیت خراب شد؟** آپدیت‌کننده برنامه را بدون پورت بازکرده. همان راه‌حل: بستن کامل → اجرا با شورتکات.
- ‏**شورتکات چیزی نشان نمی‌دهد؟** در حالت `-Gui` لانچر خبرها را با message box می‌گوید و همهٔ تصمیم‌ها در `%TEMP%\qoder-rtl.log` (لانچر) و `%TEMP%\qoder-rtl-injector.out.log` / `.err.log` (تزریق) نوشته می‌شود.
- ‏**injector در حال اجراست؟** در Task Manager دنبال `node.exe` بگردید. برای متوقف‌کردن فقط injector:

  ```powershell
  Get-CimInstance Win32_Process -Filter "Name='node.exe'" |
    Where-Object { $_.CommandLine -match 'injector\.mjs' } |
    ForEach-Object { Stop-Process -Id $_.ProcessId }
  ```

- ‏**لانچر Qoder را پیدا نمی‌کند؟** در Setup مسیر `Qoder.exe` یا `Qoder IDE.exe` را با Browse انتخاب کنید؛ یا `QODER_RTL_EXE` را روی مسیر کامل فایل اجرایی بگذارید.
- ‏**حذف نصب:** دستور بالا برای نصب سورس است؛ برای نصب‌کنندهٔ AgentRTL از Settings → Apps خود **AgentRTL** را حذف کنید.

## 🔒 نکتهٔ امنیتی

‏تا وقتی Qoder از طریق شورتکات اجرا شود، یک پورت DevTools روی `127.0.0.1:9225` باز است که **هر پردازهٔ محلی** می‌تواند به آن وصل شود — یعنی خواندن و نوشتن کامل روی پنجره‌های IDE. فقط روی localhost است، ولی روی سیستم‌های اشتراکی به یاد داشته باشید، و وقتی کارتان تمام شد Qoder را ببندید.

## ⚙️ چطور کار می‌کند

‏شورتکات، `launch.vbs` را با `wscript.exe` اجرا می‌کند (یک پروسهٔ GUI، پس هیچ‌وقت پنجرهٔ کنسول باز نمی‌شود) و آن هم یک لانچر PowerShell مخفی، `start.ps1` را بالا می‌آورد. لانچر نسخهٔ فعال Qoder را پیدا می‌کند، با `--remote-debugging-port=9225`اش اجرا می‌کند، منتظر باز شدن پورت می‌ماند و بعد `injector.mjs` را مخفی استارت می‌کند.

‏اینجکتور به پروتکل DevTools کرومیوم وصل می‌شود و اتصال خودکار سشن‌ها را با `Target.setAutoAttach { flatten: true }` می‌خواهد؛ این یک سشن به ازای هر page **و** هر iframe/webview می‌دهد، و داخل هر سشن در همهٔ execution contextها تزریق می‌کند و با `Page.addScriptToEvaluateOnNewDocument` بعد از ناوبری هم دوباره تزریق را نگه می‌دارد. جاروب ۵ ثانیه‌ای فقط شبکهٔ ایمن است:

```css
:is(p, li, h1, h2, h3, blockquote, td, label, ...) , textarea, [contenteditable="true"] {
  unicode-bidi: plaintext; /* جهت = اولین حرف قوی */
  text-align: start;
}
:is(pre, code, ...) /* به‌علاوهٔ ترمینال، ادیتور، درخت فایل، تب‌ها */ {
  unicode-bidi: isolate !important;
  text-align: initial !important;
}
```

‏`plaintext` به هر پاراگراف اجازه می‌دهد جهت خودش را انتخاب کند؛ پس یک پیام می‌تواند هم پاراگراف فارسی داشته باشد هم انگلیسی و هر دو درست نمایش داده شوند. جهت و تراز هر هدینگ بر اساس اولین نویسهٔ جهت‌دار تعیین می‌شود و خانه‌های جدول وسط‌چین هستند. استایل‌شیت هم به‌صورت یک `CSSStyleSheet` تصویب‌شده و هم به‌صورت یک `<style id="qoder-rtl-fix-v4">` دوقلو اعمال می‌شود، پس روی هر دو مسیر از بررسی CSP رد می‌شود. شناسهٔ نسخه‌دار باعث می‌شود پس از ارتقا، CSS قدیمی که نشست باز Qoder هنوز بعد از reload تزریق می‌کند جایگزین استایل جدید نشود.
