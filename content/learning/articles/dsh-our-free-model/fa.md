# dsh-our-free-model: کانال مدل رایگان (غیررسمی)

افزونهٔ غیررسمی که بدون ورود، ثبت‌نام یا کلید API چند مدل جاری — مثل DeepSeek V4.1 Flash و Kimi K3 — را در انتخاب‌گر مدل Harness می‌آورد. لاین‌های رایگان مستقیم به دروازه‌های عمومی وصل می‌شوند و کانال‌های حساب اختیاری هم دارد.

## نصب

دستورهای عمومی در [افزونه‌های DeepSeek Harness](/learning/dsh-plugins-basics). نسخهٔ پین‌شدهٔ مستندشده در README مخزن:

```bash
dsh plugin --profile web add @ebony-vinyl/dsh-our-free-model@2.8.5
```

نسخهٔ سازگار با نسخهٔ Harness خود را همیشه از README مخزن بررسی کنید. در این دستگاه نسخهٔ ۲.۸.۵ روی پروفایل وب نصب است.

## استفاده و دستورهای پایه

- پس از نصب و بازکردن دوبارهٔ Harness، لاین‌ها در انتخاب‌گر مدل ظاهر می‌شوند.
- کنسول افزونه — وضعیت لاین‌ها، داشبورد مصرف و لاگ‌های اجرا.
- کلید پنجرهٔ سهمیه — یک 429 واقعی، آن لاین را برای مدت پیش‌فرض ۶ ساعت قفل می‌کند و افزونه در این پنجره درخواست نمی‌فرستد؛ «تلاش پس از تغییر خروجی» پنجره را می‌بندد.
- تست خروجی — اتصال را با سرویس سوم بی‌هزینه می‌سنجد و سهمیه نمی‌سوزاند.
- پروکسی خروجی — برای هر لاین می‌توان `http`/`https`/`socks5` جداگانه گذاشت یا از `HTTP_PROXY` محیط استفاده کرد.
- دروازهٔ OpenAI محلی و انتقال در LAN برای ابزارهای دیگر هم دارد.

## نکته‌ها و هشدارها

- لاین رایگان یعنی سهمیهٔ عمومی بر پایهٔ IP خروجی؛ نه پایدار است نه تضمین‌شده. سهمیهٔ رایگان، API رایگان نامحدود نیست — همان هشدار [ورود وب دیپ‌سیک](/learning/dsh-deepseek-web-login).
- بدنهٔ درخواست به سرویس‌دهندهٔ همان لاین می‌رود؛ برای کار حساس یا محرمانه استفاده نکنید.
- کانال‌های حساب از حساب سرویس‌های دیگر استفاده می‌کنند؛ شرایط همان سرویس را رعایت کنید و بدانید کانال هر لحظه می‌تواند قطع شود.
- افزونهٔ شخص ثالث است؛ منبع، تغییرهای نسخه‌ها و مجوزها را پیش از اتکا مرور کنید و برای به‌روزرسانی از دستور update همان مقالهٔ عمومی با نسخهٔ جدید استفاده کنید.
