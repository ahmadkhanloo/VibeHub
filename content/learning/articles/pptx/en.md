# pptx

Create and edit PowerPoint presentations.

## Install

In Codex, ask $skill-installer to install pptx from https://github.com/anthropics/skills/tree/main/skills/pptx. Alternatively, copy this skill folder into .agents/skills/pptx/ in your project. Review its source first.

## Use

Select $pptx and describe your task with the relevant file or project. Start a new session if the skill is missing.
