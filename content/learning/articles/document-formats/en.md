# Working with PDF, Word, Excel and PowerPoint

Four official skills for documents: reading, creating and reviewing PDFs; building and editing Word documents; working with spreadsheets and formulas; and building and editing PowerPoint decks. All four follow the same pattern — only the final output differs.

## Install

All four skills come from one official repository. Ask your agent's skill installer to install pdf, docx, xlsx or pptx from the [official skills repo](https://github.com/anthropics/skills). Manual route: place that skill's folder in the project's `.agents/skills/<skill-name>/` — review the source first.

## Use

Pick the matching skill and describe the task with the relevant file or project:

- **pdf** — read, create and review PDF files.
- **docx** — build and edit Word documents.
- **xlsx** — work with spreadsheets and formulas.
- **pptx** — build and edit PowerPoint decks.

If a skill does not appear, start a fresh session.

## Baseline

Host compatibility, prerequisites, removal and troubleshooting are identical for all skills: see [installing and managing skills](/learning/skill-basics).
