# RepoWise: هوش مخزن در کنار ایجنت

فشرده‌سازی خروجی‌های پرحجم، ارزیابی ریسک تغییر و بررسی سلامت کد.

## چه می‌دهد

سه کاربرد دارد: کمک به درک کد و معماری، کم‌کردن حجم خروجی ابزارها پیش از خواندن، و سنجش ریسک و سلامت تغییر. هیچ‌کدام جای خواندن کد یا اجرای تست را نمی‌گیرد.

## نصب و اولین قدم

```bash
repowise --version
repowise status
```

`status` وضعیت ایندکس را نشان می‌دهد. اگر تعداد صفحه‌ها صفر بود، بخش‌های وابسته به ایندکس (`context`، `search`، `ask`) خالی برمی‌گردند تا `repowise init` اجرا شود؛ و `init` از مدل استفاده می‌کند و هزینه دارد. بی‌دلیل اجرا نکنید.

بدون ایندکس هم این‌ها کار می‌کنند: `health`، `risk`، `dead-code`، `distill`، `expand`.

## فشرده‌کردن خروجی

```bash
repowise distill npm test
repowise distill git diff
repowise expand <ref>
```

`distill` دستور را اجرا می‌کند و نسخهٔ کوتاه و برگشت‌پذیر خروجی را می‌دهد؛ `expand` بخش حذف‌شده را برمی‌گرداند. برای خروجی تست، `distill` فقط شکست‌ها و خلاصه را نگه می‌دارد.

هرجا خروجی دقیق خودش شاهد است — فهرست کامل شکست‌ها، عدد نهایی، رفتار غیرقابل‌تکرار — خروجی خام را نگه دارید. خلاصهٔ ابزار جای شاهد اصلی نیست.

## ریسک و سلامت

```bash
repowise health
repowise risk
repowise impacted-tests main...HEAD
```

- `health` بدون مدل و شبکه اجرا می‌شود و امتیاز سلامت فایل‌ها را می‌دهد.
- `risk` ریسک تغییرهای commit‌نشده را تخمین می‌زند.
- `impacted-tests` به دادهٔ پوشش تست نیاز دارد و جای اجرای سویت کامل را نمی‌گیرد، به‌ویژه پیش از انتشار.

این‌ها ابزار تشخیص‌اند، نه اثبات درستی.

## سینک ایندکس

```bash
repowise hook install
```

پس از نصب هوک، ایندکس بعد از هر commit خودکار به‌روز می‌شود. در نسخهٔ ۰.۴۵ دستوری به نام `update` و `doc-drift` وجود ندارد؛ فهرست واقعی دستورها را با `repowise --help` ببینید. `repowise reindex` فقط ایندکس جست‌وجو را از صفحه‌های موجود بازمی‌سازد و کد را بهتر نمی‌کند.

## تبدیل به روال کاری ایجنت

ابزار زمانی مفید است که بخشی از روال باشد، نه یک اجرای یک‌باره: پیش از تغییر، وضعیت و زمینه؛ حین کار، `distill` برای خروجی پرحجم؛ پس از کار، `health`/`risk` و سپس اجرای واقعی تست‌ها. قاعده‌های این روال را می‌توانید در فایل دستورالعمل پروژه (مثل `AGENTS.md`) بنویسید تا ایجنت هر بار بخواند.
