# اضافه‌کردن و بروزرسانی آموزش افزونه‌ها

پس از نصب نسخه‌ای از VibeHub که دریافت آموزش افزونه‌ها از فید را پشتیبانی می‌کند، تغییر محتوای این پوشه به نصاب تازه نیاز ندارد.

## روش ساده از مرورگر

1. در GitHub فایل `content/learning/extensions.json` را باز کنید و Edit را بزنید.
2. برای آموزش جدید، یکی از اشیای موجود را کپی کنید و با رعایت ویرگول‌های JSON به آرایه اضافه کنید. برای اصلاح آموزش، همان مورد را ویرایش کنید.
3. `id` انگلیسی و یکتا، `name` نام قابل نمایش، `kind` یکی از `skill`، `plugin` یا `extension`، `source` لینک HTTPS منبع اصلی و `checked` تاریخ واقعی بررسی به شکل `YYYY-MM-DD` است.
   برای دسته‌بندی، `topic` یکی از `ui`، `documents`، `testing`، `models`، `integrations` یا `extensions`، سطح `level` یکی از `beginner`، `intermediate` یا `advanced` و ترتیب `order` یک عدد صحیح از صفر تا ۱۰۰۰۰ است. فیلدها برای کش و فیدهای قدیمی اختیاری‌اند. تصاویر هر دسته همراه برنامه و آفلاین‌اند؛ تصویر موضوع تازه فعلاً به نسخهٔ جدید نیاز دارد.
4. برای `summary`، `compatibility`، `prerequisites`، `install`، `use`، `remove` و `troubleshoot`، متن فارسی `fa` و انگلیسی `en` را وارد کنید. تاریخ بررسی را بدون بررسی واقعی تغییر ندهید. رایگان‌بودن، محدودیت‌ها و روش ورود را از منبع اصلی بررسی کنید.
5. تغییر را روی `main` ثبت کنید، یا Pull Request بسازید و پس از بررسی ادغام کنید.
6. در Actions اجرای موفق **Publish VibeHub content feed** را بررسی کنید. تغییر فایل به‌تنهایی قبل از موفقیت انتشار در اختیار کاربران نیست. GitHub Pages باید با منبع GitHub Actions فعال باشد.

برای متن چندخطی در JSON از `\n` استفاده کنید. برای نوع `extension` مسیر نصب در ویرایشگر و شناسه یا لینک دقیق افزونه را در متن نصب توضیح دهید. تعداد آموزش‌ها ثابت نیست؛ فهرست خالی هم مجاز است. شناسهٔ تکراری، ترجمهٔ خالی، تاریخ نامعتبر یا محتوای اجرایی ناامن پذیرفته نمی‌شود. کل فایل دریافتی حداکثر ۲ مگابایت است.

## دریافت توسط کاربران

- برنامه هنگام شروع، بازگشت فوکوس و هر ۱۵ دقیقه در حالت قابل مشاهده، فید را بررسی می‌کند؛ بررسی خودکار تا ۱۵ دقیقه پس از آخرین دریافت موفق تکرار نمی‌شود.
- دکمهٔ **بروزرسانی آموزش‌ها** در صفحهٔ پلاگین و اسکیل، بدون انتظار برای این فاصله دریافت را انجام می‌دهد. دکمهٔ بروزرسانی محتوا در تنظیمات نیز همین فید را دریافت می‌کند.
- محتوای معتبر پیش از نمایش بررسی و سپس در حافظهٔ محلی ذخیره می‌شود. قطع اینترنت یا محتوای نامعتبر، داده‌های فعلی را تغییر نمی‌دهد.
- فید قدیمی که فایل آموزش‌ها را ندارد (HTTP 404)، آموزش‌های فعلی را نگه می‌دارد. پاک‌کردن کش محتوا، آموزش‌های همراه نصاب را برمی‌گرداند.
- این مسیر فقط محتوا را بروزرسانی می‌کند؛ قابلیت تازه در خود نرم‌افزار همچنان نسخهٔ جدید می‌خواهد.

## بررسی محلی

```sh
pnpm content:validate
node --test tests/content-site.test.mjs packages/core/tests/learning.test.mjs
```

فید از `learning/extensions.json` سرو می‌شود. گردش‌کار موجود با تغییر `content/**` یا `docs/tutorials/**` اجرا می‌شود. برای تغییر متن آموزش برنامه‌های موجود، فایل‌های `docs/tutorials/<app-id>/fa.md` و `en.md` را ویرایش کنید.
