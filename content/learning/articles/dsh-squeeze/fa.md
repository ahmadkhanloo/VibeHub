# dsh-squeeze: خواندن مطلب طولانی بدون پرشدن گفتگو

یک ابزار به گفتگو اضافه می‌کند: `squeeze`. صفحهٔ وب طولانی، چند صفحه، فایل متنی بزرگ یا PDF را با مدل کمکیِ انتخابی شما می‌خواند و فقط پاسخ را برمی‌گرداند؛ اصل مطلب وارد زمینهٔ اصلی نمی‌شود و هزینهٔ توکن آن پرداخت نمی‌شود.

## نصب

دستورهای عمومی در [افزونه‌های DeepSeek Harness](/learning/dsh-plugins-basics). برای این افزونه:

```bash
dsh plugin --profile desktop add github:q8atnight/dsh-squeeze
```

## پیکربندی

در تنظیمات افزونه:

- مدل پیش‌فرض و تا دو مدل کمکی دیگر از فهرست مدل‌های Harness؛ برای هرکدام یک لقب کوتاه (`quick`، `careful`) و یک خط «کی استفاده شود».
- سطح تفکر ثابت برای هر مدل؛ ایجنت نمی‌تواند تغییرش دهد.
- سقف اندازهٔ مطلب از پنجرهٔ زمینهٔ همان مدل حساب می‌شود (پیش‌فرض: ۸۰٪، باقی برای تفکر و پاسخ).
- کلید fallback اختیاری برای وقتی مدل اصلی در دسترس نیست یا مطلب در آن جا نمی‌شود.

## دستور پایه

شکل فراخوانی که ایجنت انجام می‌دهد:

```
squeeze  url: https://example.com/report.pdf
         prompt: جریمهٔ دیرکرد ثبت‌نام چقدر است؟ شمارهٔ بند را نقل کن.
```

به‌جای `url:` می‌توان مسیر فایل متن یا PDF داد. خط وضعیت در پایان مدل پاسخ‌دهنده، زمان و حجم منبع را نشان می‌دهد و خطاها می‌گویند قدم بعدی چیست.

## نکته‌ها

- بدنهٔ مطلب به سرویس‌دهندهٔ مدل کمکی فرستاده می‌شود؛ با fallback فعال ممکن است به سرویس‌دهندهٔ دیگری هم برود. دادهٔ حساس نفرستید.
- خواندن فایل فقط از سرویس فایل Harness انجام می‌شود؛ مسیر سیاست‌شده `ACCESS DENIED` می‌دهد.
- PDF بدون لایهٔ متن (اسکن) با پیام `SOURCE PROBLEM` رد می‌شود و OCR لازم دارد.
- کاربردهای معمول: بیرون کشیدن عدد از گزارش بلند، پیدا کردن یک بخش در لاگ یا کد بزرگ، مقایسهٔ چند صفحهٔ وب، خلاصهٔ پیاده‌گویی.
