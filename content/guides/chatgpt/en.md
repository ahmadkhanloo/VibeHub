# ChatGPT / Codex

## Overview
ChatGPT desktop and legacy Codex detection, with a standalone Codex account panel in VibeHub.

## Install
Install the Windows app from the [official website](https://chatgpt.com/download/), then refresh the app list.

## Launch and proxy
The selected profile is requested on the next launch. Close an existing app yourself first. Routing all app traffic through the proxy is not verified.

## Plugins and skills
Open Plugins and skills in Guides for installation steps and compatibility information.

## Codex accounts
The Codex accounts panel works without VS Code. It requires Codex CLI 0.148.0; follow the [official CLI guide](https://learn.chatgpt.com/docs/cli). In your terminal, run `npm install -g @openai/codex@0.148.0` if needed. Sign-in uses the official browser flow. This panel does not switch ordinary ChatGPT chat accounts. Live Windows desktop switching has not yet been verified.
