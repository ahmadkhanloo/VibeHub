# DeepSeek Harness RTL

> **یادداشت آداپتر قدیمی (۲۰۲۶-۱۰-۲۶):** این سند آداپتر RTL حفظ‌شدهٔ AgentRTL برای DeepSeek Harness را توضیح می‌دهد. نصب‌کنندهٔ قدیمی جزو انتشار VibeHub نیست و جایگزینی این قابلیت تأیید نشده است. [ماتریس پذیرش انتشار](../../docs/validation/VibeHub_Release_Acceptance_Matrix.md) را ببینید.

متن فارسی و دیگر زبان‌های راست‌به‌چپ را در DeepSeek Harness خوانا می‌کند. لانچر برنامه را با پورت محلی Chromium DevTools اجرا می‌کند و بعد stylesheet را به چت تزریق می‌کند. ورودی تایپ را هم پوشش می‌دهد؛ جهت انگلیسی را خودکار نگه می‌دارد و کد را چپ‌به‌راست باقی می‌گذارد. فونت Vazirmatn همراه ابزار است.

راهنمای آداپتر قدیمی را در [VibeHub](../../README.fa.md) ببینید و در نصب‌کننده گزینهٔ **DeepSeek Harness RTL** را انتخاب کنید. خود DeepSeek Harness و Node.js نسخهٔ ۲۱ یا جدیدتر باید از قبل نصب باشند.

قبل از اجرای شورتکات RTL، DeepSeek Harness را کامل ببندید. اگر برنامه از قبل بدون پورت دیباگ باز باشد، لانچر توضیح می‌دهد که آن را ببندید و دوباره اجرا کنید؛ خودش برنامه را نمی‌بندد.

پورت پیش‌فرض برنامه `9228` است و با متغیر `DEEPSEEK_HARNESS_RTL_PORT` عوض می‌شود. قفل injector روی پورت بعدی است. کد پروژه تحت مجوز [MIT](../../LICENSE) است؛ مجوز فونت SIL Open Font License 1.1 در `assets/OFL.txt` قرار دارد.
