# Superpowers: working-method skills for your agent

A collection of "how to work" skills installed as an agent plugin: brainstorming before coding, writing and executing plans, test-driven development, systematic debugging, code review, and verification before declaring work done.

## What it gives you

The skills transfer a working method rather than a tool: the agent clarifies requirements before implementing, writes a plan before restructuring, and runs a real test before claiming completion. None of it replaces your judgement — the skills steer the agent's behaviour, they do not decide.

## Install and first step

The plugin installs from the agent's plugin marketplace; after install, each agent's plugin cache holds a `superpowers` folder and the skill list lives inside it. To start, invoke the brainstorming skill before a new feature and let the agent ask its questions before writing code.

## Real limits

Skills are text guidance, not magic: their effect depends on the model and the project's own advice. If a skill does not fit your workflow, rewrite it rather than tolerate the friction — the skill-creator skill exists for exactly that. VibeHub reports whether the plugin is present in the helper-tools card on the Apps page.
