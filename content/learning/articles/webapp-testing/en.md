# webapp-testing

Test a local web app with Playwright.

## Install

In Codex, ask $skill-installer to install webapp-testing from https://github.com/anthropics/skills/tree/main/skills/webapp-testing. Alternatively, copy this skill folder into .agents/skills/webapp-testing/ in your project. Review its source first.

## Use

Select $webapp-testing and describe your task with the relevant file or project. Start a new session if the skill is missing.
