## Features / امکانات

### مسیر و سطح فعلی آموزش‌ها

کتابخانهٔ اسکیل و افزونه بر اساس موضوع و سطح قابل فیلتر است. فیلدهای `topic`، `level` و `order` در فایل JSON، دسته، سطح و ترتیب را مشخص می‌کنند. ترتیب درس‌های هر برنامه همان عنوان‌های Markdown است. اسناد چهارگانه در یک مجموعه قرار می‌گیرند و راهنمای هر فرمت جدا حفظ شده است.

- **Qoder:** مسیر مرتب مقدماتی (انتخاب محصول، نصب، شناخت IDE و دسکتاپ، مدل رایگان، اعتبار روزانه)، کاربردی (تمرین کوچک)، تکمیلی (BYOK و رفع مشکل).
- **Claude Code:** شروع از ترمینال و اتصال به درگاه LiteLLM، بررسی مسیر واقعی و محدودیت سازگاری مدل‌های دیگر؛ نصب و اتصال واقعی آزموده نشده است.
- **سایر برنامه‌ها:** راهنمای شروع/نصب، RTL و رفع مشکل؛ عمق و میزان تکمیل یکسان نیست. فهرست نه برنامه در جدول بالا آمده است.
- **افزونه‌ها:** ۱۱ مورد: ورود وب DeepSeek، frontend-design، webapp-testing، pdf، docx، xlsx، pptx، skill-creator، GitHub، Figma و OpenAI Developers. ورود وب DeepSeek تکمیلی است و به آشنایی اولیه با Harness نیاز دارد.
- **آموزش‌های عمومی:** نصب RTL، کارهای طولانی با دستیار و بازبینی کد. راهنمای بازبینی کد: [فارسی](code-review/fa.md) · [English](code-review/en.md).
