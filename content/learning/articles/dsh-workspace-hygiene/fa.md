# dsh-workspace-hygiene: نظم فضای کار ایجنت

کارهای طولانی ایجنت انبوه فایل میانی می‌سازند؛ فضای کار شلوغ یعنی جست‌وجوی بیشتر، توکن بیشتر و استدلال نویزتر. این افزونه ارزش فایل‌ها را می‌سنجد و پیشنهاد می‌دهد؛ تصمیم نهایی با شماست.

## نصب

دستورهای عمومی در [افزونه‌های DeepSeek Harness](/learning/dsh-plugins-basics). برای این افزونه:

```bash
dsh plugin --profile desktop add github:taoshi1999/dsh-workspace-hygiene
```

## دستورها و استفاده

- پانل افزونه — ارزش‌سنجی دسته‌ای فایل‌ها و پوشه‌ها با مدل نشست جاری؛ دکمهٔ Refresh ارزیابی را دوباره اجرا می‌کند.
- پیشنهادها — برای هر فایل: نگه‌داشتن (با نام و پوشهٔ پیشنهادی)، حذف یا بی‌تصمیمی برای بررسی شما؛ می‌پذیرید، ویرایش یا رد می‌کنید.
- حالت automatic — پیشنهادها در پایان هر دور گفتگو ارائه می‌شود؛ `autoScan: false` پایش دوره‌ای را خاموش می‌کند.
- ابزار ایجنت `workspace_hygiene_review` — تنها ابزاری که برای ایجنت اصلی ثبت می‌شود.
- بازبینی جداگانه — پیش از اعمال، یک نشست headless جدا فقط با ابزار `hygiene_verdict` شواهد را بررسی می‌کند؛ بازبینی منفی یعنی بازگشت تغییر.

## نکته‌ها

- ارزیابی مدل‌محور توکن و سهمیه مصرف می‌کند و برای فضای کار بزرگ در چند دسته می‌رود؛ خطای مدل یا پوشش ناقص، سازمان‌دهی را متوقف می‌کند.
- تاریخچهٔ گفتگوی افزونه در `~/.dsh-workspace-hygiene/private` با AES-256-GCM رمز می‌شود و رمز ذخیره نمی‌شود؛ رمز گم‌شده یعنی تاریخچه بازیابی‌ناپذیر.
- تفکیک ارزش‌گذاری از عمل عمدی است: فایل‌های بی‌ارزش روشن حذف می‌شوند و موردهای نامشخص برای شما می‌مانند. پیشنهاد حذف را پیش از پذیرفتن بخوانید.
- برای الگوی کارهای طولانی، [واگذاری کارهای طولانی به ایجنت](/learning/long-running) را ببینید.
