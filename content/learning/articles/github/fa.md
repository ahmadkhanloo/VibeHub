در پایان می‌توانی کار دستیار را به‌عنوان کامیت روی مخزن گیت‌هاب خودت بفرستی.

## آماده شو

GitHub میزبان مخزن‌های Git است؛ کامیت‌های محلی روز قبل پیش‌نیاز این درس‌اند. برای کار با گیت‌هاب حساب رایگان لازم داری: در [github.com](https://github.com/signup) بساز و ایمیلت را تأیید کن.

اپ کدنویسی‌ات را روی مخزن تمرینی دیروز باز کن؛ اگر هنوز مخزن نداری، درس [اولین تغییرت را با Git ثبت کن](/learning/git-first-commit?category=git) را کامل کن.

## مخزن را به GitHub وصل کن

اول در GitHub یک مخزن خالی به نام `first-vibe` بساز؛ بدون README و بدون لایسنس تا با مخزن محلی‌ات قاطی نشود. بعد در ترمینال پروژه، نشانی مخزن را ثبت و بفرست:

```powershell
git remote add origin https://github.com/<username>/first-vibe.git
git push -u origin main
```

به‌جای `<username>` نام کاربری خودت را بگذار. اولین push احراز هویت می‌خواهد؛ اگر مرورگر باز شد ورود بزن، اگر توکن خواست از تنظیمات حساب GitHub توکن بساز.

چک‌پوینت: صفحهٔ مخزن در مرورگر، فایل‌های پروژه و کامیت‌های دیروز را نشان می‌دهد.

## کار دستیار را به کامیت برسانی

حالا یک خواستهٔ واقعی بده؛ مثلاً: «یک بخش «درباره من» به صفحه اضافه کن.» وقتی دستیار کارش تمام شد و تو تفاوت‌ها را خواندی و پذیرفتی:

```powershell
git add -A
git status
```

پیام کامیت را از توضیحی که دستیار برای رفعش داد بردار — درس دیباگ همین را گفت:

```powershell
git commit -m "Add about section"
git push
```

چک‌پوینت: در تب Commits مخزن، کامیت تازه را می‌بینی و صفحهٔ تغییرشده در گیت‌هاب به‌روز است.

## از اپ و پلاگین GitHub هم می‌شود استفاده کرد

برخی اپ‌ها پلاگین یا اتصال آمادهٔ GitHub دارند: در ChatGPT بخش Plugins، در Codex CLI فرمان `/plugins` و مارکت‌پلیس تنظیم‌شده. با اتصال، دستیار می‌تواند ایشو بخواند یا درخواست ادغام بسازد؛ دسترسی‌اش همان مجوزهای حساب متصل تو است. راهنمای نصب، حذف و رفع مشکل در [نصب و مدیریت اسکیل‌ها](/learning/skill-basics?category=skills) آمده است.

اتصال پلاگین جای Git محلی را نمی‌گیرد؛ هر دو هم‌زمان کار می‌کنند.

## خودت امتحان کن

یک تغییر کوچک دیگر بده، تفاوت را بخوان، کامیت بزن و push کن. بعد در گیت‌هاب تب Commits را باز کن: باید بتوانی در یک نگاه بگویی هر کامیت چه عوض کرد. اگر اسم کامیت گویا نبود، همین حالا قاعدهٔ خودت را بنویس: «فعل + چه چیزی» مثل Add about section.
