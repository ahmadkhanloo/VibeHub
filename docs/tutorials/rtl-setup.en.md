# Persian text and right-to-left launch

## Set up the adapter

If the app card shows **Set up RTL**, select it and confirm. VibeHub uses its bundled adapter to create a shortcut under **Start → VibeHub**. If the adapter is unavailable, use the link in the setup window to install the full VibeHub package.

## Try it once

Fully quit the app, including its tray process. Select **Run RTL** and type a Persian sentence with an English phrase and a number. Check the conversation and the input field. Code and the terminal should stay left-to-right. Use **Run** for a normal launch.

For Persian in PowerShell, see [Terminal and Persian text](/terminal).
