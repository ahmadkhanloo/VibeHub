# GitHub

Work with repositories, issues and pull requests.

## Install

In ChatGPT desktop, open Plugins, search for GitHub, review its details, install it and complete the requested connection. In Codex CLI use /plugins and your configured marketplace.

## Use

Start a new chat/session and select @GitHub, or describe the relevant task. Access follows the connected account permissions.
