# skill-creator

Create and improve a reusable skill.

## Install

In Codex, ask $skill-installer to install skill-creator from https://github.com/anthropics/skills/tree/main/skills/skill-creator. Alternatively, copy this skill folder into .agents/skills/skill-creator/ in your project. Review its source first.

## Use

Select $skill-creator and describe your task with the relevant file or project. Start a new session if the skill is missing.

## Getting started

See [Install and manage skills](/learning/skill-basics) for host compatibility, prerequisites, removal, and troubleshooting.
