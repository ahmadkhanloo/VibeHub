# OpenAI Developers

Use current OpenAI documentation and API guidance.

## Install

In ChatGPT desktop, open Plugins, search for OpenAI Developers, review its details, install it and complete the requested connection. In Codex CLI use /plugins and your configured marketplace.

## Use

Start a new chat/session and select @OpenAI Developers, or describe the relevant task. Access follows the connected account permissions.
