# VibeHub 0.2.3-beta.1 release preparation

Requested by the repository owner on 2026-11-02 (Asia/Tehran). This release packages the changes requested in the current conversation.

## Changes

- Remove repetitive navigation-name tooltips while the sidebar labels are visible.
- Unify guides and learning under one navigation entry, with common workflow and RTL instructions collected separately from app-specific instructions.
- Show diagnostic groups before running, update groups independently, preserve partial results and reset stale results on rerun.
- Offer optional confirmed installation of the pinned RtlTerminal 1.1.4 host for connected Persian letters in PowerShell, with SHA-256 verification and explicit elevation requirements. This does not patch Windows Terminal or change the default host/profile.
- Remove the limited app-version/update panel and unused backend request. Installed-version labels remain; the VibeHub updater remains available.
- Replace the outdated offer-notification test expectation with assertions that the existing switch is visible and off, retaining the check that page entry never requests notification permission.
- Run the isolated Persian-terminal installer checks in Windows CI and release preflight.

## Release classification

The base application version is 0.2.3 and the publication tag is `v0.2.3-beta.1`. Gate 18 clean Windows acceptance is still unverified. The stable-release gate and the historical owner exceptions were not changed or extended.

The existing stable updater uses the latest stable release; this prerelease is available by direct download and does not replace that stable channel.

## Evidence and limits

The implementation and its prior checks are recorded in [the implementation report](20261101_learning_diagnostics_terminal.md). Additional verification and publication status belong to the linked PR and GitHub Actions runs, rather than being inferred from a tag or a started workflow.

No installed RtlTerminal rendering test or new clean-machine acceptance is claimed. Updater archive signing is distinct from Windows publisher Authenticode signing; the public installer remains without a publisher certificate.
