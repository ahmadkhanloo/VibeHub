# find-skills: پیدا کردن اسکیل مناسب

پیش از ساختن یک اسکیل تازه، ببینید اسکیل آماده‌ای برای آن کار هست یا نه. find-skills جست‌وجو در اکوسیستم باز اسکیل‌ها را برای شما و ایجنت ساده می‌کند.

## چه می‌دهد

جست‌وجوی اسکیل بر اساس کاری که می‌خواهید (نه نام دقیق)، معرفی محبوب‌ترین گزینه‌ها و دستور نصب آماده. مرجع فهرست: skills.sh.

## جست‌وجو و نصب

```bash
npx skills find react performance
npx skills add vercel-labs/agent-skills@react-best-practices -g
```

پیش از نصب سه چیز را بسنجید: شمار نصب (ترجیحاً بالای ۱۰۰۰)، اعتبار منبع (مخازن رسمی مثل `vercel-labs` و `anthropics` معتبرترند) و ستاره‌های مخزن. اسکیل‌های زیر ۱۰۰ نصب را با احتیاط بگیرید.

## مرزهای واقعی

اسکیل نصب‌شده فقط متن راهنما به ایجنت می‌دهد: هیچ ابزاری اجرا نمی‌شود و درستی محتوایش تضمینی ندارد. اسکیل‌ها به‌ازای هر ماشین زیر `.agents/skills` نصب می‌شوند؛ بعد از نصب، یک کار کوچک واقعی را با آن امتحان کنید تا مطمئن شوید به جریان کاری شما می‌خورد.
