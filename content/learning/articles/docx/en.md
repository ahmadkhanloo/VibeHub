# docx

Create and edit Word documents.

## Install

In Codex, ask $skill-installer to install docx from https://github.com/anthropics/skills/tree/main/skills/docx. Alternatively, copy this skill folder into .agents/skills/docx/ in your project. Review its source first.

## Use

Select $docx and describe your task with the relevant file or project. Start a new session if the skill is missing.
