درس ۳ از ۳ · زمان پیشنهادی: ۵ دقیقه برای انتخاب تمرین

در پایان می‌توانی منبع متناسب با نیازت را انتخاب کنی.

لازم نیست همهٔ این منابع را بخوانی؛ با تمرین فارسی شروع کن.

## از این تمرین شروع کن

### Learn Git Branching — انتخاب اول

*مقدماتی تا پیشرفته · فارسی · تمرین بصری*

با تمرین‌های مقدماتی commit، branch و merge شروع کن و اثر فرمان‌ها را روی درخت ببین. این محیط شبیه‌سازی است و جای تمرین روی فایل‌های واقعی و اتصال GitHub را نمی‌گیرد.

[بازکردن در مرورگر](https://learngitbranching.js.org/?locale=fa)

### GitByBit — تمرین با Git واقعی

*مقدماتی · انگلیسی · تمرین در ویرایشگر*

طبق توضیح سازنده، نتیجهٔ تمرین با Git واقعی در ویرایشگر سازگار بررسی می‌شود؛ دورهٔ اصلی رایگان و بخش تکمیلی PRO پولی است. نصب و اجرای آن در این بررسی آزموده نشده است.

[بازکردن در مرورگر](https://gitbybit.com/)

## وقتی به توضیح یا راه‌حل نیاز داری

### Pro Git فارسی

*همهٔ سطوح · فارسی · مرجع متنی*

برای فهم عمیق‌تر، بخش مرتبط را بخوان؛ لازم نیست کتاب را از ابتدا تا انتها تمام کنی. فصل دوم برای ثبت تغییرات و ریموت و فصل سوم برای شاخه‌بندی مناسب‌اند.

[کتاب؛ بازکردن در مرورگر](https://git-scm.com/book/fa/v2)

- [ثبت تغییرات؛ بازکردن در مرورگر](https://git-scm.com/book/fa/v2/مقدمات-گیت-git-basics-chapter-ثبت-تغییرات-در-مخزن-Recording-Changes-to-the-Repository)
- [شاخه‌بندی؛ بازکردن در مرورگر](https://git-scm.com/book/fa/v2/انشعاب‌گیری-در-گیت-Git-Branching-شاخه‌بندی-و-ادغام-پایه‌ای-Basic-Branching-and-Merging)
- [ریموت؛ بازکردن در مرورگر](https://git-scm.com/book/fa/v2/مقدمات-گیت-git-basics-chapter-کار-کردن-با-ریموت-ها-Working-with-Remotes)

### Git Flight Rules

*متوسط تا پیشرفته · انگلیسی · رفع مشکل*

مسئلهٔ خودت را پیدا کن و قبل از اجرای راهکار، اثر آن بر فایل‌ها و تاریخچه را بخوان. این منبع مسیر شروع برای مبتدی نیست.

- [مقصد راه دور اشتباه؛ بازکردن در مرورگر](https://github.com/k88hudson/git-flight-rules#i-set-the-wrong-remote-repository)
- [پیام کامیت اشتباه؛ بازکردن در مرورگر](https://github.com/k88hudson/git-flight-rules#i-wrote-the-wrong-thing-in-a-commit-message)
- [حل تعارض ادغام؛ بازکردن در مرورگر](https://github.com/k88hudson/git-flight-rules#there-were-conflicts)

## اگر این شیوه را بیشتر دوست داری

### Get-Git

*مقدماتی تا متوسط · انگلیسی · مرور کارتی*

برای مرور کوتاه فرمان‌ها مناسب است، اما کارت‌ها نتیجهٔ اجرای فرمان را بررسی نمی‌کنند. در نمونه‌های بررسی‌شده خطای نگارشی فرمان هم وجود داشت؛ آن را مرجع قطعی اجرای فرمان ندان.

[بازکردن در مرورگر](https://github.com/ParsaBordbar/get-git)
