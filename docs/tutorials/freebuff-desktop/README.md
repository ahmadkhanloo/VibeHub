# Freebuff Desktop guides

The bilingual guides in this folder cover the distinct Desktop product. The catalog keeps its `freebuff-desktop` ID separate from the `freebuff` CLI entry. The official download page offers macOS, Windows and Linux builds. No executable path or renderer has been verified locally, so RTL remains unavailable and no app-specific selectors are applied.

# راهنماهای Freebuff Desktop

راهنماهای دوزبانهٔ این پوشه مربوط به محصول دسکتاپ هستند. صفحهٔ رسمی نسخه‌های macOS، Windows و Linux را دارد. شناسهٔ آن در کاتالوگ (`freebuff-desktop`) از شناسهٔ CLI یعنی `freebuff` جداست. فایل اجرایی و renderer این برنامه در نصب محلی بررسی نشده‌اند؛ بنابراین RTL در دسترس نیست و انتخابگر اختصاصی تزریق نمی‌شود.
