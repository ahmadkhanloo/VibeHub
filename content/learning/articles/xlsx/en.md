# xlsx

Work with spreadsheets and formulas.

## Install

In Codex, ask $skill-installer to install xlsx from https://github.com/anthropics/skills/tree/main/skills/xlsx. Alternatively, copy this skill folder into .agents/skills/xlsx/ in your project. Review its source first.

## Use

Select $xlsx and describe your task with the relevant file or project. Start a new session if the skill is missing.
