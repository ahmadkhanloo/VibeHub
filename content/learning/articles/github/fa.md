# GitHub

کار با مخزن، ایشو و درخواست ادغام.

## نصب

در اپ ChatGPT بخش Plugins را باز کنید، GitHub را جست‌وجو و جزئیات را بررسی کنید؛ نصب و اتصال درخواستی را کامل کنید. در Codex CLI از /plugins و مارکت‌پلیس تنظیم‌شده استفاده کنید.

## استفاده

چت یا نشست تازه‌ای باز کنید و @GitHub را انتخاب کنید یا کار مرتبط را توضیح دهید. دسترسی تابع مجوز حساب متصل است.

## راهنمای پایه

سازگاری میزبان، پیش‌نیازها، حذف و رفع مشکل را در آموزش [نصب و مدیریت اسکیل‌ها](/learning/skill-basics) ببینید.
