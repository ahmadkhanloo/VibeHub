# Spec Kit

[GitHub Spec Kit](https://github.com/github/spec-kit) is an open-source toolkit for specification-driven development with a coding agent. It supplies templates and agent workflows for describing a feature, planning it and verifying the implementation.

1. **Specify.** Write the user need, concrete examples and acceptance criteria. Example: an empty budget form shows which fields are required.
2. **Plan.** Decide the structure, storage and tests after the requirements are clear.
3. **Break the plan into tasks.** Make each task small enough to review and verify.
4. **Implement and verify.** Compare the result with the specification and revise the plan when the requirements change.

Follow the official setup and command reference for your agent. Try it first in an exercise repository and review the files it produces after each step.
