# dsh-context: دیدن زمینهٔ گفتگو

نگاه به زمینه: داشبورد مصرف توکن و هزینه، ترکیب و تحول زمینه و کارت زندهٔ ایجنت‌ها. همه از آمار محلی Harness می‌خواند؛ مدل را صدا نمی‌زند و چیزی به زمینه اضافه نمی‌کند.

## نصب

دستورهای عمومی نصب و حذف در [افزونه‌های DeepSeek Harness](/learning/dsh-plugins-basics). برای این افزونه:

```bash
dsh plugin --profile desktop add dsh-context
```

به‌روزرسانی:

```bash
dsh plugin --profile desktop update dsh-context@latest
```

از داخل برنامه هم در Plugin Market با جست‌وجوی `dsh-context` نصب می‌شود.

## دستورهای پایه

- `/context` — دستور اسلش در گفتگو: ترکیب زمینهٔ فعلی و تحول اخیر را نشان می‌دهد.
- پانل Context در نوار کناری — آمار نشست، ترکیب، روند، رویدادها، پیام‌ها و اجرای دستورها.
- تب Fleet — کارت زندهٔ ایجنت جاری، والدش و هر زیرایجنت.
- نمای کلی نشست‌ها — نمودار مصرف ۷ روز (توکن و هزینه)، نقشهٔ فعالیت و کارت‌های نشست با پرش مستقیم.

## استفاده

پس از نصب و بازکردن دوبارهٔ Harness، یک گفتگوی کوتاه اجرا کنید و `/context` را بزنید. بعد پانل Context را از نوار کناری باز کنید و ترکیب زمینه را ببینید؛ برای کارهای واگذارشده تب Fleet را باز کنید تا وضعیت زیرایجنت‌ها را زنده ببینید.

## نکته‌ها

- فقط‌خواندنی است؛ مصرف توکن و شبکه ندارد.
- آمار نشست‌های پیش از نصب کامل نیست.
- اگر `/context` دیده نشد: افزونه را در بخش Plugins فعال کنید و Harness را دوباره باز کنید.
