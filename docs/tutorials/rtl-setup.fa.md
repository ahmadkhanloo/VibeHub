# نصب RTL پس از نصب برنامهٔ کدنویسی

[English](rtl-setup.en.md)

## نصب و شناسایی برنامه

Qoder، ZCode، DeepSeek Harness یا اپ مستقل Antigravity را از منبع رسمی نصب کنید. به وایب‌هاب برگردید؛ با گذشت پنج ثانیه از بررسی قبلی، فهرست هنگام بازگشت تازه می‌شود. دکمهٔ «بررسی دوباره» در صفحهٔ برنامه‌ها نیز همین کار را انجام می‌دهد. برنامهٔ شناسایی‌شده کاشی خودش را خواهد داشت.

## نصب RTL از کاشی

روی «نصب RTL» بزنید و تأیید کنید. وایب‌هاب از فایل‌های RTL و محیط Node خصوصیِ همراه خودش استفاده می‌کند تا میانبر آن برنامه را در **Start → VibeHub** بسازد و اجرای بعدی از میزکار را راست‌چین کند. این کار برنامه را اجرا یا بسته نمی‌کند؛ فایل‌های برنامهٔ مقصد و حساب‌های آن را تغییر نمی‌دهد و به دانلود محیط اجرای دیگری نیاز ندارد.

اگر فایل‌های لازم موجود نباشند، بستهٔ کامل وایب‌هاب را از صفحهٔ رسمی انتشار که در همان پنجره لینک شده نصب کنید و دوباره بررسی کنید. نصب برنامهٔ مقصد به‌تنهایی فایل‌های RTL وایب‌هاب را فراهم نمی‌کند.

## اجرا و تغییر حالت

اگر برنامه بدون RTL باز است، پیش از «اجرای RTL» یا استفاده از میانبر منوی شروع، خودتان آن را کاملاً ببندید؛ خروج از قسمت کنار ساعت هم ممکن است لازم باشد. دکمهٔ حالت اجرا کنار دکمهٔ اصلی امکان بازگشت به اجرای عادی را دارد. برای حذف میانبر، فقط میانبر RTL همان برنامه را از Start → VibeHub حذف کنید. نصب دوباره همان میانبر متعلق به وایب‌هاب را بازسازی می‌کند و میانبر نامرتبط را بازنویسی نمی‌کند.

## وضعیت آنتی‌گرویتی

RTL چتِ اپ مستقل Antigravity آزمایشی است و با Antigravity IDE تفاوت دارد. نصب آن از کاشی و صفحهٔ همان برنامه در دسترس است. نمایش متن ترکیبی فارسی و انگلیسی در گفت‌وگوی واقعیِ حساب واردشده هنوز نیاز به تأیید سازگاری زنده دارد؛ موفقیت نصب فقط ساخت میانبر را ثابت می‌کند.

## دفترچهٔ API

دفترچهٔ API نشانی سرویس، شناسهٔ مدل و کلید اختیاری را ذخیره می‌کند. آزمون اختیاری اتصال، درخواست واقعی می‌فرستد. اطلاعات مدخل را در تنظیمات خود برنامهٔ کدنویسی وارد کنید. صفحهٔ مستقل پروکسی مسیر درخواستیِ اجرای بعدی برنامه را تنظیم می‌کند؛ ثبت یک API در دفترچه، برنامهٔ مقصد را خودکار پیکربندی نمی‌کند.
