# UI/UX Pro Max: design and review interfaces

A design skill backed by searchable data: 79 visual styles, 192 product palettes, 74 font pairings, 119 UX guidelines and stack-specific support — for designing, building, reviewing and fixing web, mobile and desktop interfaces.

## What it gives you

- **Data-driven design:** style, palette and typography chosen from curated sets instead of free-form taste.
- **Interface review:** spacing, hierarchy, accessibility, responsiveness and interaction.
- **Charts and icons:** 105 icons, 25 chart types and 17 GSAP animation presets.

## When to use it

While building a new page or component, redesigning, or whenever an interface "works but feels off". Ask the agent to run this skill over your file or page.
