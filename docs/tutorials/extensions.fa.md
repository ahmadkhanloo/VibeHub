# راهنمای پلاگین و اسکیل

## frontend-design

[Source](https://github.com/anthropics/skills/tree/main/skills/frontend-design)

طراحی رابط وب با جهت بصری مشخص.

اسکیل محلی Codex و بخش Codex اپ ChatGPT در صورت دسترسی به اسکیل محلی؛ برای عامل دیگر پشتیبانی خود ابزار را بررسی کنید.

عامل دارای پشتیبانی اسکیل؛ پیش‌نیازهای محیط اجرا، مرورگر و ابزار سند را در SKILL.md بررسی کنید.

در Codex از $skill-installer بخواهید frontend-design را از https://github.com/anthropics/skills/tree/main/skills/frontend-design نصب کند. روش دستی: پوشه همین اسکیل را در .agents/skills/frontend-design/ پروژه قرار دهید. ابتدا منبع را بررسی کنید.

اسکیل $frontend-design را انتخاب کنید و کار را همراه فایل یا پروژه مرتبط توضیح دهید. اگر دیده نشد، نشست تازه‌ای باز کنید.

فقط پوشه اسکیل نصب‌شده را حذف کنید یا مسیر همان اسکیل را با [[skills.config]] در پیکربندی Codex غیرفعال کنید؛ پس از تغییر پیکربندی دوباره اجرا کنید.

## GitHub

[Source](https://github.com/github/github-mcp-server)

کار با مخزن، ایشو و درخواست ادغام.

محیط‌های ChatGPT/Codex دارای پشتیبانی پلاگین؛ دسترسی به حساب و فضای کاری وابسته است. افزونه VS Code مسیر نصب دیگری دارد.

دسترسی به فهرست پلاگین‌ها و حساب یا مجوزهای درخواستی سرویس مربوط.

در اپ ChatGPT بخش Plugins را باز کنید، GitHub را جست‌وجو و جزئیات را بررسی کنید؛ نصب و اتصال درخواستی را کامل کنید. در Codex CLI از /plugins و مارکت‌پلیس تنظیم‌شده استفاده کنید.

چت یا نشست تازه‌ای باز کنید و @GitHub را انتخاب کنید یا کار مرتبط را توضیح دهید. دسترسی تابع مجوز حساب متصل است.

پلاگین نصب‌شده را باز کنید و در صورت دسترسی Uninstall را بزنید. برای لغو اتصال سرویس، اتصال مربوط را جداگانه قطع کنید.
