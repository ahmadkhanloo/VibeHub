## Start with practice

### Learn Git Branching — first choice

*Beginner to advanced · Persian · visual exercises*

Start with introductory commit, branch and merge exercises and watch the tree change. This is a simulation, not practice with real files or GitHub authentication.

[Open in browser](https://learngitbranching.js.org/?locale=fa)

### GitByBit — real Git practice

*Beginner · English · editor exercises*

According to its author, it checks exercise results using real Git in a compatible editor; the main course is free and PRO content is paid. Installation and execution were not tested in this review.

[Open in browser](https://gitbybit.com/)

## When you need an explanation or solution

### Pro Git in Persian

*All levels · Persian · text reference*

Read the relevant section rather than the whole book. Chapter 2 covers recording changes and remotes; chapter 3 covers branching.

[Book — open in browser](https://git-scm.com/book/fa/v2)

### Git Flight Rules

*Intermediate to advanced · English · troubleshooting*

Find your specific problem and understand the effects on files and history before running a recipe. This is not the beginner starting path.

- [Wrong remote — open in browser](https://github.com/k88hudson/git-flight-rules#i-set-the-wrong-remote-repository)
- [Wrong commit message — open in browser](https://github.com/k88hudson/git-flight-rules#i-wrote-the-wrong-thing-in-a-commit-message)
