# Ponytail: the shortest solution that works

Ponytail turns the agent into a professional slacker: the simplest, shortest, least-dependent solution that actually works — the mindset a senior engineer uses to walk past over-engineering.

## What it gives you

- **Question first, code second:** does this work need to exist at all? (YAGNI)
- **Standard library before custom code, native platform features before new dependencies.**
- **Three intensities:** `lite` for a light touch, `full` (default) and `ultra` for maximum strictness.

## When to use it

On any coding task: writing, fixing, reviewing, choosing a library — or whenever an agent's output feels bigger and more complex than the problem. Just say "ponytail" or "simplest solution".

## Install state

The workspace chip reports whether Ponytail is present among the agent's local skills.
