# Plugins and skills

## frontend-design

[Source](https://github.com/anthropics/skills/tree/main/skills/frontend-design)

Design a web interface with a clear visual direction.

Local Codex skills; Codex in ChatGPT desktop where local skills are available. For another agent, check its own support.

A skill-capable agent. Read SKILL.md for runtime, browser and document-tool dependencies.

In Codex, ask $skill-installer to install frontend-design from https://github.com/anthropics/skills/tree/main/skills/frontend-design. Alternatively, copy this skill folder into .agents/skills/frontend-design/ in your project. Review its source first.

Select $frontend-design and describe your task with the relevant file or project. Start a new session if the skill is missing.

Remove only the installed skill folder, or disable its exact path using [[skills.config]] in Codex configuration. Restart after configuration changes.

## GitHub

[Source](https://github.com/github/github-mcp-server)

Work with repositories, issues and pull requests.

Supported ChatGPT/Codex plugin surfaces; availability depends on your account and workspace. VS Code extensions use another installation path.

Plugin-directory access and the provider account or permissions requested by the plugin.

In ChatGPT desktop, open Plugins, search for GitHub, review its details, install it and complete the requested connection. In Codex CLI use /plugins and your configured marketplace.

Start a new chat/session and select @GitHub, or describe the relevant task. Access follows the connected account permissions.

Open the installed plugin and choose Uninstall where available. Disconnect the linked service separately if you also want to revoke that connection.
