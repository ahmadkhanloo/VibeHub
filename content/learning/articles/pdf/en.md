# pdf

Read, generate and inspect PDF files.

## Install

In Codex, ask $skill-installer to install pdf from https://github.com/anthropics/skills/tree/main/skills/pdf. Alternatively, copy this skill folder into .agents/skills/pdf/ in your project. Review its source first.

## Use

Select $pdf and describe your task with the relevant file or project. Start a new session if the skill is missing.
