# MiMo Code — راهنمای فارسی

## معرفی
MiMo Code ایجنت کدنویسی CLI شیائومی است؛ کد تحت MIT منتشر می‌شود اما شرایط سرویس میزبانی و محدودیت‌های استفاده جداگانه‌اند.

## دسترسی رایگان
- کد متن‌باز (MIT) است؛ مدل/سرویس میزبانی شرایط خودش را دارد.
- سهمیه‌هایی که «موقت» معرفی شده‌اند را دائمی فرض نکنید؛ وضعیت را در [منبع رسمی](https://github.com/XiaomiMiMo/MiMo-code) ببینید.

## نصب
طبق [مستندات رسمی](https://mimo.xiaomi.com/mimocode/start). VibeHub فرمان `mimo` را در PATH تشخیص می‌دهد.

## اولین اجرا
«باز کردن در ترمینال» با پروفایل پروکسی منتخب. ادعای RTL تا آزمون واقعی نداریم (وضعیت: نامشخص).

## پروکسی و دسترسی از ایران
آزمون‌نشده. متغیرهای پروکسی استاندارد هنگام اجرا تزریق می‌شوند.

## ترمینال
راه‌اندازی ترمینال VibeHub برای این CLI هم قابل استفاده است (اختیاری).

## عیب‌یابی
- اگر فرمان پیدا نشد: پس از نصب، ترمینال را ببندید و باز کنید.

## گزینه‌های مدل
طبق مستندات رسمی؛ وضعیت BYOK نامشخص تا آزمون.
